# Normalización

## Objetivo

Documentar el proceso de normalización de la base de datos hasta Tercera Forma Normal (3FN).

Se analizarán:

- Primera Forma Normal (1FN).
- Segunda Forma Normal (2FN).
- Tercera Forma Normal (3FN).

Se justificarán las decisiones de diseño adoptadas para evitar redundancia, anomalías de actualización y problemas de integridad.

> Este documento será completado una vez definido el Modelo Entidad–Relación.
