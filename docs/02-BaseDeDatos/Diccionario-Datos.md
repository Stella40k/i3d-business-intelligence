# Diccionario de Datos

## Objetivo

Definir todos los atributos de las entidades del sistema, especificando:

- Nombre del campo.
- Tipo de dato.
- Longitud.
- Obligatoriedad.
- Valor por defecto.
- Restricciones.
- Claves primarias.
- Claves foráneas.
- Índices.
- Descripción funcional.

> Este documento será completado una vez finalizado el Modelo Entidad-Relación (MER).
