# Objetivo

Definir la planificación general del desarrollo del sistema mediante una estrategia incremental basada en sprints.

Cada sprint representa un incremento funcional del producto y finaliza con código estable, documentación actualizada y pruebas realizadas.

# Criterios de finalización de un sprint

Cada sprint se considerará finalizado únicamente cuando se hayan completado las siguientes actividades:

- Análisis funcional.
- Diseño técnico.
- Desarrollo.
- Pruebas.
- Documentación.
- Commit y publicación en GitHub.

---

# Gestión de versiones

Cada funcionalidad importante será desarrollada en una rama independiente y posteriormente integrada a la rama `dev`.

La rama `main` contendrá únicamente versiones estables del sistema.
